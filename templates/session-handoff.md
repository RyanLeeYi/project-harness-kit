# Session Handoff

> **覆寫這份檔案，不要往下追加。** 它要回答的是「現在在哪」，不是「走過哪些路」——歷史留給 git log 與 DEVLOG。

**更新於**：<< YYYY-MM-DD >>
**當前 feature**：<< F1 — 標題 >>
**分支**：<< feature/F1-xxx >>

## 現況

<< 做到哪。哪幾條 acceptance 已經過、證據在哪 >>

## 下一步

<< 接手的人第一件事該做什麼。具體到可以直接動手 >>

## 卡點

<< 卡在哪、試過什麼、排除了什麼假設。沒有就寫「無」 >>

## 給接手者的提醒

<< 環境怪癖、踩過的坑、暫時的繞道。沒有就刪掉這段 >>
